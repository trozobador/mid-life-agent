# Guia de Preparação para Entrevista

## 1. Análise do Cargo

A empresa está em busca de um Engenheiro de Dados altamente qualificado com experiência em Microsoft Fabric e Azure Databricks. O candidato ideal deve ter expertise profunda em frameworks de ingestão de dados, arquiteturas modernas de engenharia de dados e integração de dados entre ambientes Fabric e Databricks. A função envolve o design e implementação de pipelines de dados escaláveis, espelhamento de dados do Databricks para o Microsoft Fabric, e habilitação de análises através de Modelos Semânticos e relatórios Power BI.

### Top 3 "Must-Haves"
1. Experiência prática com Microsoft Fabric e Azure Databricks.
2. Capacidade de desenvolver e manter soluções de engenharia de dados end-to-end.
3. Fluência em inglês para colaborar com clientes baseados nos EUA.
